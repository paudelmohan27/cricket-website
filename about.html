What Is
CricVerse?

CricVerse is a clean, fast, and modern cricket hub built for fans who want the game — not the clutter. No pop-ups, no irrelevant noise. Just live scores, real stats, and streams.

Every piece of data you see comes directly from cricapi.com in real-time. Matches, rankings, series — all live, nothing hardcoded. The Watch Live section streams real broadcasts via embedded players.

Built with pure HTML, CSS and JavaScript — no frameworks, no bloat. Fast by design and beautiful by choice. Deploys anywhere as static files.

API SETUP

01
Get API Key
Sign up free at cricapi.com. The free tier includes 100 calls/day — enough for a personal fan site.
02
Set the Key
Open script.js and replace YOUR_CRICAPI_KEY with your actual key on line 9.
03
Deploy
Push the 6 files to GitHub. Enable Pages under Settings → Pages → main branch. Done — your site is live.
